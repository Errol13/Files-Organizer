# Smart File Organizer

A Python automation tool that organizes files in a given path/directory into categorized folders (e.g. '.pdf' files in Given_Path/Documents).

## Features
- Automatically sorts files by type
- Creates folders if they don’t exist
- Supports images, documents, audio, videos, archives
- Dry run the files organization before proceeding

## Usage

```bash
python3 main.py
